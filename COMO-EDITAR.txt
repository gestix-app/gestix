# Gestix Web — versión editable

## Dónde cambiar cosas

### 1. Precios, Mercado Pago, textos y enlace de ingreso
Abrí `script.js` y buscá:

`GESTIX_CONFIG`

Ahí podés modificar:
- `loginUrl` → enlace del botón Ingresar a Gestix
- `topbar` → texto superior
- `heroTitle` / `heroHighlight` → título principal
- `heroText` → descripción
- `plans.Inicial.price` → precio Inicial
- `plans.Profesional.price` → precio Profesional
- `plans.Premium.price` → precio Premium
- `checkoutUrl` → enlace de Mercado Pago de cada plan

### 2. Tamaño de logos y colores
Abrí `style.css` y arriba de todo buscá `GESTIX — CONFIGURACIÓN VISUAL FÁCIL`.

Podés cambiar:
- `--gestix-logo-header`
- `--gestix-logo-hero`
- `--gestix-logo-footer`
- `--gestix-blue`
- `--gestix-blue-dark`
- `--gestix-bg`

### 3. Logos
Los archivos están en la misma carpeta que `index.html`, por lo que no hay que moverlos a una carpeta `assets`.

## Para publicar
Subí a la raíz de GitHub los archivos del ZIP. Si reemplazás `index.html`, `style.css` y `script.js`, los cambios se reflejan en GitHub Pages después de unos instantes.
